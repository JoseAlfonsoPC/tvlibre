# Configurarlo con Codex

El prompt completo está en **[prompts/CODEX.md](prompts/CODEX.md)**.

1. Clona el repositorio y abre la carpeta en Codex.
2. Sustituye la IP de ejemplo y las preferencias.
3. Pega el bloque de texto completo como petición.
4. Acepta en el televisor la autorización ADB cuando aparezca.

También hay un [prompt de diagnóstico sin cambios](prompts/REVISAR.md) y otro de
[restauración](prompts/RESTAURAR.md).
